# Social Media Trends & Engagement Analysis

## Project Overview
This project focuses on identifying and analyzing trending technology topics across social media platforms. It explores audience engagement, content performance, and platform-wise trends to understand how technology-related content performs across different social media channels.

The analysis covers LinkedIn, Instagram, and YouTube, using social media metrics to identify popular topics and engagement patterns.

## Objectives
- Identify trending technology topics and hashtags.
- Analyze social media engagement across different platforms.
- Compare likes, comments, shares, and views.
- Evaluate engagement across different content formats.
- Identify high-performing topics and posting patterns.
- Generate meaningful insights through data visualization.

## Tools & Technologies
- **Excel** – Data cleaning and data preparation.
- **SQL** – Data filtering, extraction, and aggregation.
- **Power BI** – Interactive dashboards and data visualization.

## Dataset
The cleaned dataset contains **247 social media records** collected across three platforms:

- LinkedIn – 119 records
- YouTube – 82 records
- Instagram – 46 records

**Data collection period:** 30 October 2026 – 18 November 2026.

## Key Analysis
- Platform-wise engagement analysis.
- Technology topic and hashtag performance.
- Likes, comments, shares, and views analysis.
- Content format performance comparison.
- Social media activity and posting frequency.
- Identification of engagement trends and patterns.
